# 跨平台移植验证记录（2026-11-05，0.3.0）

| 功能 | Android / Windows 实现 |
| --- | --- |
| 原版界面、动效、中英文、横屏、左右换边 | 复用原版 HTML/CSS/JS，不重新设计 |
| 天气和本地时段 | Geolocation + Open-Meteo；Android 授权后继续原请求 |
| 整张专辑探索 / 我的喜欢 | 复用原候选来源与 Spotify Web API |
| AtmosRank | 天气/时间目标、情绪匹配、近期/跳过惩罚、艺人分隔、活力连续性、Softmax 抽样 |
| 500 张专辑标签 | 公开来源的低置信度元数据估计；保留来源和置信度，不分发个人评分 |
| 六维评分 | 复用原版弹窗和 15 秒实际播放计时；只在缓存确认收藏后触发；本机保存并用于下次推荐 |
| 健身 | 计划编辑、动作完成/替补、强律动筛选；无已知候选时提示，不捏造特征 |
| Windows 后台队列 | C# 原生推荐、独立 Token 刷新、五秒播放状态采样、十五秒队列检查、六首预加载、落盘恢复；与 UI 共用同一推荐计划 |
| Android 连续播放 | 复用专属私人歌单；最多 30 首一批，前台剩余八首时追加，单会话最多 300 首；使用当前 `/playlists/{id}/items` 接口 |

| 播放、暂停、续播、定位 | Spotify Connect；命令串行，续播不附带 URI/起点；丢弃跨命令的旧状态响应 |
| 进度、歌词、自动换歌动画 | 共用播放状态事件与平滑时钟；前台轮询实际播放器 |
| 歌词 | LRCLIB 精确查询→放宽专辑→搜索；校验标题、艺人、时长，有限重试，旧歌曲响应由原 UI 丢弃 |
| 专辑简介 | Pitchfork 短简介、评分、原文链接、可用的中文翻译及原版详情弹窗；服务失败明确提示 |

## 实际完成的验证

- Swift / JavaScriptCore：62 项测试通过，包括原版推荐、队列恢复、防重复、歌词时钟和新增跨平台公式对照。
- Node VM 中运行公开集成测试：14 项通过，新增 Android 私人歌单、权限不足、索引切歌、无重启续播、重复点击及响应丢失后的核对。
- C# 原生测试：20 项通过，涵盖无浏览器请求时自动补歌和 Token 刷新、UI/队列同序、模式暂停、重启防重复、429 退避、外部播放接管检测、无重启续播及录入评分。
- Android：JDK 17 / SDK 35 / Gradle 8.9 `assembleDebug` 成功。
- Windows：.NET 8 `publish -r win-x64` 成功。
- 本机服务烟雾检查：实际运行同源 C# 服务，页面和会话脚本返回 200，Windows 平台识别与状态接口正常，无主机密钥的接口请求被拒绝。没有使用真实 Spotify 凭据。

## 尚未验收及平台边界

- 未在真实 Android、Windows 设备上完成 Spotify 授权、付费账号播放、锁屏耗尽队列、断网及系统回收测试。模拟测试不能代替这些验收。
- 未新增 Android 前台后台服务；WebView 休眠后由 Spotify 播放已生成歌单，耗尽后需前台生成更多。Windows 已摆脱浏览器计时器，但仍依赖 EXE 进程、电脑唤醒和网络。
- Windows 仍是默认浏览器 + 本地服务；音频仍由 Spotify 输出。没有改成内嵌桌面播放器。
- 现有他人/其他来源队列不会被删除、清空或强行重排。队列冲突会保留并提示。
- 第三方天气、歌词、简介、翻译的可用性不由 App 保证。Spotify 403、404、429 会保留状态并提示，不会以“成功”掩盖。
- 本次未修改实际 iOS 项目的 UI、Spotify SDK、登录授权、Bundle ID 或签名。
- Windows DPAPI 凭据持久化的真实 Windows 运行验收，以及 Android 的真实 Spotify 授权和锁屏测试，仍需目标设备完成。
